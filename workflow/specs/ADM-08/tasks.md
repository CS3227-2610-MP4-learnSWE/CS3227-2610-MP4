# Tasks: ADM-08 Feedback hub

Phases follow `workflow/plans/CONSOL-01-migration-plan.md` (this feature is phase 3, the Feedback hub) with the cleanup of ADM-02, ADM-03 and ADM-04 deferred into this feature as phase 5, mirroring ADM-07. Each phase ends at a human gate; tasks of a later phase start only after its gate. Orchestration is lighter than ADM-07 (migration plan decision 3): test-designer and developer in parallel with tests first, one verifier pass per phase. The template's separate cross-user and concurrent-request tasks (6 and 7) are not created: the feature adds no stored records and only one read-only endpoint, whose cross-admin and concurrent-read tests are inside P3-3, and the existing ADM-02, ADM-03 and ADM-04 backend suites keep covering them unchanged. Standing rules: the old features keep working and passing until phase 5; real data only; `ai_usage.cleanup` is never run by any task; AI only through the shared SoC LLM client with ADM-03's server-side protections unchanged. The orchestrator owns the run manifest and usage report for each run (`workflow/coordination.md`).

# ADM-07 retained criteria (task P5-1)

Purpose: the final text of the old ADM-01 and ADM-06 acceptance criteria that stay true after the old specs are deleted in phase 5. Sources: `workflow/specs/ADM-01/spec.md` (AC1-AC45), `workflow/specs/ADM-01/privacy-amendment.md` (approved 2026-11-10, controls AC23 and related), `workflow/specs/ADM-06/spec.md` (AC1-AC13 plus its 2026-11-06 clarifications). Criteria text is copied; the ADM-07 column follows `spec.md` "Retained criteria" (R1-R6) and "Deviations from ADM-01 and ADM-06". ADM-07 ids (R1 to R6) are the mapping ids in that table.

Test files are named only (not inspected for per-criterion coverage here). Backend tests are under `src/backend/tests/`, frontend under `src/frontend/tests/`. Shared helpers (not tests): `adm01_fixtures.py`, `adm01_helpers.py`, `adm01_grading_helpers.py`, `adm01_tea02.py`, `adm01Api.ts`. Where several files are listed, which one covers a given criterion was not verified; the verifier or developer should confirm before deleting any test file in phase 5. Files that cover a superseded criterion must not be deleted until an ADM-07 test covers the replacement.

Status column: **Kept** = true unchanged; **Changed** = true with an ADM-07 change (stated); **Superseded** = listed in the second half.
